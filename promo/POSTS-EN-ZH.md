## Friend install note (EN + 繁中)

**EN:** Download the DMG → open → drag to Applications. If macOS says “damaged”:  
`xattr -cr /Applications/BAA.app`

**繁中：** 下載 DMG → 打開 → 拖去「應用程式」。若顯示「已損毀」：  
`xattr -cr /Applications/BAA.app`
